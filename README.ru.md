# Revit Server Stack

[English version](README.md)

Запускайте Autodesk Revit Server 2020-2027 в Docker на одном компьютере с Windows, несколько версий одновременно, и управляйте ими из небольшой локальной веб-панели.

Dockerfile для Revit Server 2020-2025 взяты из [dosymep/revit-server-docker](https://github.com/dosymep/revit-server-docker). Dockerfile для 2026 и 2027 написаны заново, потому что Autodesk изменила формат установщика (см. [Revit Server 2026 и 2027](#revit-server-2026-и-2027)). Этот проект также добавляет панель управления, настройку обратного прокси и документацию.

## Что внутри

| Часть | Где лежит | Что делает |
| --- | --- | --- |
| Dockerfile | `src/rs<год>/` | Один образ на каждую версию Revit Server. Установщик скачивается с серверов Autodesk во время сборки. |
| Панель управления | `panel/`, `Start-Panel.cmd` | Локальный веб-интерфейс: запуск, остановка, пересборка и настройка, вывод docker в реальном времени. |
| Запуск из трея | `RevitServerStack.exe`, исходники в `launcher/` | Значок в области уведомлений: запускает панель без окна консоли и открывает её в браузере. |
| Обратный прокси | создаётся панелью, пример в `samples/` | nginx на порту 80, который направляет запрос нужной версии по году в адресе. |
| Примеры compose | `samples/` | Обычные compose-файлы для работы без панели. |

## Требования

- Windows 10 или 11 с Docker Desktop. Контейнеры Revit Server работают на Windows-движке (docker-контекст `desktop-windows` по умолчанию), прокси работает на Linux-движке. Панель показывает состояние обоих и умеет переключать движок.
- Windows PowerShell 5.1, он входит в состав Windows. Больше ничего устанавливать не нужно.
- Место и время: образ занимает около 14 ГБ, первая сборка скачивает около 5 ГБ и идёт от 20 до 45 минут.
- Доступ к серверам загрузки Autodesk во время сборки. Сборки 2026 и 2027 дополнительно скачивают 7-Zip с github.com.
- Право на использование Revit Server, см. [Правовая информация](#правовая-информация).

## Быстрый старт

1. Скачайте `RevitServerStack-<версия>.zip` на странице [Releases](../../releases) и распакуйте. В этой папке хранятся ваши настройки и, по умолчанию, модели (`samples\rs<год>`), поэтому распакуйте её на диск с достаточным свободным местом.
2. Запустите `RevitServerStack.exe`. В области уведомлений появится значок, а панель откроется в браузере по адресу `http://localhost:8787/`. В меню значка есть «Открыть панель», «Журнал запуска» и «Выход». Выход останавливает панель, но не контейнеры.
3. Найдите карточку нужной версии и нажмите «Собрать и запустить». Вывод сборки виден в реальном времени.
4. Когда карточка покажет, что версия работает, откройте страницу администратора:
   - через прокси: `http://localhost/RevitServerAdmin2022/`
   - напрямую: `http://localhost:2022/RevitServerAdmin2022/`

   Вместо 2022 подставьте свой год. После запуска серверу нужно некоторое время, пока страница начнёт отвечать.
5. Чтобы подключить Revit, см. следующий раздел.

Exe не имеет цифровой подписи, поэтому при первом запуске Windows SmartScreen или антивирус могут выдать предупреждение. Сравните SHA-256 архива с файлом `.sha256` из релиза или соберите exe сами из `launcher/RevitServerStack.cs`.

Без exe: запустите `Start-Panel.cmd` из клона репозитория (та же панель в окне консоли, остановка по Ctrl+C) или соберите exe командой `powershell -NoProfile -ExecutionPolicy Bypass -File launcher\Build.ps1`.

## Подключение Revit

Revit работает с Revit Server по WCF net.tcp через порт 808, а не по HTTP. В Revit укажите в качестве сервера имя или IP-адрес этого компьютера, без порта.

Порт 808 задан протоколом, поэтому опубликовать его может только одна версия. Откройте «Настройки» в панели, отметьте «порт 808 для Revit» у версии, к которой подключаются ваши клиенты Revit, сохраните и перезапустите эту версию. Без этого Revit выдаёт «TCP 10061, connection refused», хотя страница администратора открывается нормально.

## Панель управления

- Состояние Docker Desktop, Windows-движка и Linux-движка.
- Запуск, остановка, перезапуск, пересборка и удаление контейнера каждой версии, а также прокси. Кнопки «Запустить всё» и «Остановить всё» действуют на всё сразу.
- Собран ли образ и отвечает ли страница администратора на самом деле. Работающий контейнер ещё не означает, что IIS запустился.
- Вывод docker в реальном времени для каждой операции и история задач. Сборка продолжается, если закрыть панель и открыть её снова.
- Настройки: порт и папка с моделями для каждой версии, какие версии маршрутизирует прокси, порт прокси, docker-контексты (в том числе [Docker на другом компьютере](#docker-на-другом-компьютере)), порт панели.

Настройки сохраняются в `panel/runtime/panel.config.json`. Compose-файлы и `nginx.conf`, с которыми работает панель, она создаёт в `panel/runtime/compose/`. Эта папка не попадает в git, а файлы в `samples/` остаются нетронутыми.

Имена, которые использует панель: compose-проект `samples`, образы `samples-rs<год>`, контейнеры `rs<год>` и `revit-proxy`. При смене имени проекта docker соберёт образы заново, поэтому без причины его не меняйте.

### Языки

Панель и меню значка в трее говорят на английском, русском, немецком, французском, испанском, бразильском португальском, упрощённом китайском и японском. Панель запускается на языке браузера, а если такого языка у неё нет, на английском. Переключатель в шапке панели меняет язык, выбор запоминается в браузере. Статусы и сообщения об ошибках, которые присылает панель, идут на выбранном языке, а окно консоли и меню в трее следуют языку Windows. Названия кнопок и настроек в этом документе даны по русскому интерфейсу.

Эталон это английский и русский тексты. Остальные переводы носители языка не проверяли, исправления приветствуются, см. [CONTRIBUTING.md](CONTRIBUTING.md#translations).

### Модели

Каждая версия хранит центральные модели в папке на хосте, по умолчанию `samples/rs<год>`. Удаление или пересборка контейнера их не затрагивает. Панель создаёт папку при необходимости. Делайте резервную копию этой папки, а не контейнера.

### Безопасность

Панель слушает только `localhost`. Каждый вызов API требует токен сессии, который создаётся при запуске и подставляется в страницу при её выдаче, поэтому страница с другого источника не может ни прочитать токен, ни управлять docker через панель. Не открывайте порт панели за пределы этого компьютера: панель выполняет команды docker.

С самим Revit Server иначе. Порты версий и порт прокси опубликованы на всех сетевых интерфейсах, чтобы коллеги могли подключаться. Если компьютер находится в сети, которой вы не доверяете, ограничьте доступ брандмауэром Windows.

## Работа без панели

Версия Revit Server на Windows-движке:

```
docker --context desktop-windows compose -f samples\docker-compose.2022.yml up -d --build
```

Прокси на Linux-движке (контекст по умолчанию):

```
docker compose -f samples\docker-compose.proxy.yml up -d
```

Чтобы остановить или удалить, замените `up -d --build` на `stop` или `down`. Примеры публикуют только HTTP-порт (`2022:80`). Чтобы Revit мог подключиться, добавьте `- '808:808'` в список `ports` одной из версий. Пример `nginx.conf` маршрутизирует все восемь версий, а панель создаёт конфиг только для включённых.

## Docker на другом компьютере

Контейнеры Revit Server могут работать на сервере или на другом компьютере, а панель остаётся на вашем. Панель управляет Docker через docker-контексты, поэтому подойдёт любой движок, до которого дотягивается docker.

1. На сервере нужен Docker Engine с Windows-контейнерами и, для адреса `ssh://`, SSH-сервер с вашим ключом в `authorized_keys`. Docker CLI тоже должен быть установлен на сервере: контекст `ssh://` запускает там `docker system dial-stdio`.
2. Откройте «Настройки», раздел «Удалённый Docker». Введите имя и адрес, `ssh://пользователь@сервер` (или алиас из `~/.ssh/config`) либо `tcp://сервер:2376`, и нажмите «Добавить контекст». В терминале то же самое делает `docker context create revit-server --docker "host=ssh://пользователь@сервер"`. Для TLS нужны сертификаты, такой контекст создайте через docker CLI.
3. Выберите новый контекст в поле «Контекст Windows-контейнеров». Для каждой запускаемой версии укажите папку моделей полным путём на сервере, например `D:\RevitServerData\rs2022`. Создайте папку на сервере заранее: Docker для Windows не создаёт отсутствующую папку. Панель не создаёт её с вашего компьютера и не запустит версию, у которой папка задана иначе.
4. В брандмауэре сервера откройте порты используемых версий (по умолчанию это год версии, например 2022) и порт 808 для версии, к которой подключаются клиенты Revit.

Что меняется при удалённом движке:

- Образы собираются на сервере: контекст сборки отправляется туда, а установщики скачивает сервер.
- Ссылки, кнопка «Открыть» и проверки готовности используют адрес сервера из контекста. Для ssh-алиаса настоящее имя узла берётся из `ssh -G`. Если адрес определился неверно, задайте «Адрес Windows-сервера» в настройках.
- Прокси нужен Linux-движок, а на Windows-сервере его обычно нет. Оставьте прокси на другом движке, например на вашем Docker Desktop (поле «Контекст прокси (Linux)» не меняйте): nginx сам направится на сервер. Прокси может работать и на удалённом Linux-движке: укажите его контекст в поле «Контекст прокси (Linux)». Конфигурация nginx передаётся внутрь контейнера, с вашего компьютера ничего не монтируется. Можно обойтись без прокси и открывать версии по порту.
- Индикатор Docker Desktop и его кнопки пропадают, если ни один движок не находится на вашем компьютере.

Панель запускает docker без клавиатуры: она не может ввести пароль или подтвердить неизвестный ключ узла. Один раз подключитесь командой `ssh пользователь@сервер` в терминале и используйте ключ без парольной фразы или загрузите его в `ssh-agent`. Движок `tcp://` без TLS даёт всем в сети полный контроль над сервером, поэтому лучше `ssh://` или TLS.

## Revit Server 2026 и 2027

Autodesk поставляет эти две версии как архив 7-Zip за лаунчером интерактивной установки ODIS, а не как самораспаковывающийся установщик прежних версий. Dockerfile не запускают лаунчер. Они распаковывают архив с помощью 7-Zip (`7zr.exe`, версия 26.04, SHA-256 проверяется при сборке), достают `RevitServer.msi` вместе с файлами и устанавливают его через `msiexec` с теми же параметрами, что и у прежних версий.

Остальные отличия от 2020-2025: базовый образ `wcf:4.8-windowsservercore-ltsc2022` (Revit Server 2027 собран под .NET Framework 4.8), а загрузки идут с `damassets.autodesk.net`.

Проверено 2026-10-15: оба образа собираются и запускаются на Docker Desktop с Windows-контейнерами, страница администратора, REST-служба и порт 808 отвечают. Подключение клиента Revit не проверялось.

Autodesk публикует эти установщики, а позже и их обновления, на двух страницах поддержки: [Revit Server 2026](https://www.autodesk.com/support/technical/article/caas/tsarticles/ts/6jklbKtzdkgnbd4NTfV0zC.html) и [Revit Server 2027](https://www.autodesk.com/support/technical/article/caas/tsarticles/ts/3Gfbmiwn7RrgauBEoTIfWn.html). Dockerfile используют файл, который был там указан на 2026-10-15: `Revit_Server_2026_4_win_db.sfx.exe` (обновление 2026.4) и `Revit_Server_2027_win_db.sfx.exe`. Чтобы перейти на новое обновление, следуйте [CONTRIBUTING.md](CONTRIBUTING.md#moving-revit-server-2026-or-2027-to-a-new-update).

## Структура репозитория

```
src/rs<год>/Dockerfile    образ одной версии Revit Server
panel/                    панель управления: PowerShell и статический HTML/JS, без зависимостей
panel/tests/              самопроверки панели и запуска из трея
launcher/                 исходники RevitServerStack.exe и Build.ps1, который собирает его и архив релиза
samples/                  примеры compose и nginx для работы без панели
Start-Panel.cmd           запуск панели в окне консоли
```

## Если что-то не работает

- Панель пишет, что Windows-движок недоступен: нажмите кнопку рядом с сообщением или выполните `"%ProgramFiles%\Docker\Docker\DockerCli.exe" -SwitchWindowsEngine`.
- Сборка падает при скачивании установщика: Autodesk перенесла файл. Подставьте новую ссылку в строку `ADD` файла `src/rs<год>/Dockerfile`. На 2026-10-15 ссылки всех восьми версий отвечали HTTP 200. Для 2026 номер обновления входит в имя файла (`Revit_Server_2026_4_win_db.sfx.exe` это обновление 2026.4), поэтому для нового обновления нужна новая ссылка.
- В карточке написано «Работает, веб ещё не отвечает»: IIS внутри контейнера ещё запускается. Подождите, состояние изменится само.
- Удалённый движок показан как недоступный: выполните в терминале `docker --context <имя> ps`. Если там просят пароль или подтверждение ключа узла, либо пишут, что соединение отклонено, панель тоже не заработает, пока это не исправлено.
- Порт 808 или 80 занят: порт прокси меняется в «Настройках». Порт 808 изменить нельзя, поэтому остановите программу, которая его занимает.

## Тесты

```
powershell -NoProfile -ExecutionPolicy Bypass -File panel\tests\Invoke-Tests.ps1
```

Скрипт проверяет экранирование аргументов, проверку настроек и создаваемые файлы, запускает панель из временной копии и проверяет токен, заголовок Host и защиту путей, собирает exe и проверяет, что он запускает и останавливает панель, а также упаковывает архив релиза и смотрит его содержимое. Ему нужен git и, для двух проверок, docker CLI (без него они пропускаются). Работающий движок docker не нужен.
